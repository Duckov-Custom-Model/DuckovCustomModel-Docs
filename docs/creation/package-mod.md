# 打包模组

本文档介绍如何将自定义模型和模组dll打包成游戏模组，使其能够通过游戏的模组管理器加载。



## 准备文件

1. 创建模组文件夹（如 `jiuhu_v1.0`）
2. 将以下文件复制到该文件夹：
   - 编译好的 `mod.dll`
   - `info.ini`
   - `preview.png`（模组预览图）
   - 所有模型包文件夹。



## 模组结构

一个完整的模组应包含以下文件，Models文件夹内可以放置多个模型包：

<ModelPackage />

### 文件说明

| 文件/文件夹   | 必需 | 说明                                                 |
| ------------- | ---- | ---------------------------------------------------- |
| `Models`      | 是   | 包含模型资源的文件夹                                 |
| `ModelPack`   | 是   | 模型包文件夹，参考 [打包模型包](bundle-structure.md) |
| `mod.dll`     | 是   | 模组的主要逻辑代码                                   |
| `info.ini`    | 是   | 模组的信息                                           |
| `preview.png` | 是   | 模组预览图，显示在游戏的模组管理器中                 |
